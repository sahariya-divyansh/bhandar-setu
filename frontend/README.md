# Bhandar Setu — Frontend Web App

React 18 + TypeScript + Vite web application for the Bhandar Setu PHC medicine inventory and redistribution platform.

## Features
- Dynamic stock level trend visualizations (`recharts`)
- Client-side navigation (`react-router-dom`)
- Responsive dark UI interface built with Vanilla CSS

## Setup & Running

```bash
npm install
npm run dev
```

The application will be accessible at `http://localhost:5173`.

## Build

```bash
npm run build
```
