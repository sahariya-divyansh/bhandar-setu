# Bhandar Setu — API Specification Summary

Interactive OpenAPI documentation is dynamically generated by the FastAPI backend at `/docs` when running locally (`http://localhost:8000/docs`).

## Core Endpoints Overview

| Method | Endpoint | Description | Auth Required |
| :--- | :--- | :--- | :--- |
| `GET` | `/health` | Service health status check | No |
| `GET` | `/api/v1/facilities` | List all registered PHCs/CHCs by district | Yes |
| `GET` | `/api/v1/inventory/{facility_id}` | Fetch current medicine stock levels | Yes |
| `GET` | `/api/v1/predictions/stockouts` | Retrieve predicted stock-outs (30-60 day window) | Yes |
| `POST`| `/api/v1/redistribution/recommend` | Calculate optimal cross-facility transfer routes | Yes |
